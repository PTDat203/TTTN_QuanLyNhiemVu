# Thư mục `db/`

> **Database Oracle đang chạy là nguồn chuẩn duy nhất.**
> Code sửa theo database, không sửa database theo code.
> Schema đã được tạo thủ công — ứng dụng **không** tạo bảng, **không** dùng EF Migrations.

## Kết nối

```text
Oracle Database 21c XE
Host: 127.0.0.1   Port: 1521   Service: XEPDB1   Schema: TASK_APP
Bộ ký tự: AL32UTF8
```

## Trạng thái schema đã kiểm chứng

Kiểm bằng `sqlplus` trên database thật.

### 7 bảng

`USERS` · `USER_SKILLS` · `TASK_STATUS_LOOKUP` · `TASKS` · `TASK_PROGRESS` · `TASK_REPORTS` · `TASK_ATTACHMENTS`

### Tên cột dễ nhầm

Đây là những cột từng bị map sai trong code. Tên đúng theo database thật:

| Bảng | Cột đúng | Tên cũ đã bỏ |
|---|---|---|
| `USERS` | `USER_ROLE` | ~~`ROLE`~~ |
| `USERS` | `USER_STATUS` | ~~`STATUS`~~ |
| `TASKS` | `STATUS_CODE` | — |
| `TASK_REPORTS` | `REPORT_STATUS` | ~~`STATUS`~~ |

### Khóa chính

Cả 6 bảng có `ID` đều dùng `NUMBER GENERATED BY DEFAULT AS IDENTITY`.
`TASK_STATUS_LOOKUP` dùng `CODE VARCHAR2(30 CHAR)` làm khóa chính.

Phía C#: `long Id` + `ValueGeneratedOnAdd()`. **Không dùng `Guid`.**

### Ràng buộc UNIQUE

- `UQ_USERS_USERNAME` — `USERS(USERNAME)`
- `UQ_USERS_EMAIL` — `USERS(EMAIL)`, cho phép nhiều dòng `NULL`
- `UQ_USER_SKILL` — `USER_SKILLS(USER_ID, SKILL_NAME)`

### Ràng buộc CHECK

| Ràng buộc | Nội dung |
|---|---|
| `CK_USERS_ROLE` | `USER_ROLE IN ('MANAGER','EMPLOYEE')` |
| `CK_USERS_STATUS` | `USER_STATUS IN ('ACTIVE','INACTIVE')` |
| `CK_TASKS_PRIORITY` | `PRIORITY IN ('LOW','MEDIUM','HIGH')` |
| `CK_TASKS_DATE` | `DUE_DATE >= START_DATE` khi cả hai không NULL |
| `CK_TASK_PROGRESS_PERCENT` | `PROGRESS_PERCENT BETWEEN 0 AND 100` |
| `CK_TASK_REPORTS_STATUS` | `REPORT_STATUS IN ('CHO_XAC_NHAN','DA_XAC_NHAN','TU_CHOI')` |
| `CK_USER_SKILL_LEVEL` | `SKILL_LEVEL BETWEEN 1 AND 5` hoặc NULL |
| `CK_TASK_ATTACHMENTS_SIZE` | `FILE_SIZE >= 0` hoặc NULL |

### Index khóa ngoại

Đủ 12 cột khóa ngoại đều có index, tiền tố `IDX_`. Không cột nào thiếu.

### Ngữ nghĩa chuỗi

Toàn bộ 19 cột `VARCHAR2` dùng ngữ nghĩa `CHAR`. Nghĩa là `HasMaxLength(n)` trong EF Core
ánh xạ 1:1 với `VARCHAR2(n CHAR)`, không phải quy đổi byte.

## Lệnh kiểm tra nhanh

```sql
-- Đủ 7 bảng chưa
SELECT TABLE_NAME FROM USER_TABLES ORDER BY TABLE_NAME;

-- Tên cột và ngữ nghĩa chuỗi
SELECT TABLE_NAME, COLUMN_ID, COLUMN_NAME, DATA_TYPE, DATA_LENGTH, CHAR_USED, NULLABLE
FROM   USER_TAB_COLUMNS ORDER BY TABLE_NAME, COLUMN_ID;

-- Index
SELECT i.TABLE_NAME, i.INDEX_NAME, ic.COLUMN_NAME, ic.COLUMN_POSITION
FROM   USER_INDEXES i JOIN USER_IND_COLUMNS ic ON i.INDEX_NAME = ic.INDEX_NAME
ORDER  BY i.TABLE_NAME, i.INDEX_NAME, ic.COLUMN_POSITION;

-- Danh mục trạng thái
SELECT * FROM TASK_STATUS_LOOKUP ORDER BY SORT_ORDER;
```
